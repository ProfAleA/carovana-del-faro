# La Carovana del Faro

Un'avventura a scelte in pixel art per l'orientamento nelle classi terze della scuola secondaria di primo grado.

## Come si usa

- **Online:** il gioco è pubblicato con GitHub Pages; basta aprire l'indirizzo del sito.
- **Senza internet:** si può anche aprire il file `index.html` direttamente nel browser, da una chiavetta o dal computer.

## Privacy

- Il gioco non usa server, account o database e non fa chiamate esterne: tutto avviene nel browser dello studente.
- I testi scritti dallo studente restano sul dispositivo e non vengono analizzati né inviati.
- La Pergamena si salva solo se lo studente lo sceglie: come PDF (stampa del browser) o come file di recupero da riaprire in seguito.
- La lettura ad alta voce usa solo voci italiane installate sul dispositivo.
- GitHub, che ospita il sito, registra per sicurezza l'indirizzo IP di chi visita le pagine; il gioco non aggiunge altro.
